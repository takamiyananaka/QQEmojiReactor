## 📖 简介与使用指南 (Usage)

菜々華 (nanaka) 是一款用于简化群聊消息表情回应操作的辅助增强模块。

### 运行环境
- Android 8.0 及以上系统
- 已安装支持的主流 Xposed / LSPosed 框架环境

### 使用步骤
1. 下载并安装最新版本 APK；
2. 打开 LSPosed 管理器，在模块列表中启用 **「菜々華 (nanaka)」**；
3. **勾选作用域**：将作用域勾选为手机 QQ；
4. **重启生效**：强制停止 QQ 后重新启动；
5. 进入任意群聊，长按消息气泡并在弹出的快捷菜单中选择批量表情回应即可。
